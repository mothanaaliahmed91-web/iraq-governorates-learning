# تسلّق جبال دهوك — تقرير المرحلة الثالثة

## ما أضيف

- محطة مستقلة في مسار الرحلة باسم «تسلّق جبال دهوك»، بعد تحدي X/O وقبل جواز الرحلة.
- مشهد SVG أصلي: جبل مركزي، قمة ثلجية، مخيما بداية، مساران متمايزان، عشر محطات، متسلقان، أشجار وغيوم خفيفة وكأس القمة.
- إعداد فرق، وطول سباق سريع (6) أو عادي (8) أو كامل (10)، مع وضع أسئلة منهجي أو متنوع أو تحدٍّ.
- الصحيحة تصعد بالمتسلق محطة واحدة مع النقاط والسلسلة؛ الخطأ يبقيه في موضعه ويعرض التصحيح بلطف ثم يمرر الدور.
- سؤال قمة منفصل قبل الفوز، وزران لمراجعة الحقائق وطريقة اللعب، مع احترام وضع تقليل الحركة.

## المحتوى والأسئلة

يحتوي `mountainQuestions` في `src/data/duhok-data.js` على 22 سؤالاً معرفة بـ `id` و`factId` وموضوع ومصدر ومستوى وتفسير ونقاط. الأنواع المستخدمة: اختيار، صح/خطأ، اختيار إجابتين، المختلف، مطابقة، تصنيف، اتجاهات، أكمل، «من أنا؟»، تصحيح عبارة، وسؤال القمة.

المصدر الأساسي هو المحتوى المنهجي المرفق: الطابع الجبلي، جبال بيخير وباكرمان وكارة وعقرة، جبال طوروس، والهضاب والسهول. أضيفت حقائق إثرائية محدودة وموسومة داخل الواجهة بعبارة «معلومة إضافية»: مركز المحافظة مدينة دهوك، موقع زاخو قرب معبر إبراهيم الخليل، سهل سميل، والجبال المحيطة بالمدينة. لم تستخدم اللعبة أي أرقام سكان أو أسماء مسؤولين أو مادة سياسية.

المصدر الإثرائي موثق في ملف المشروع: [محافظة دهوك — ويكيبيديا العربية](https://ar.wikipedia.org/wiki/%D9%85%D8%AD%D8%A7%D9%81%D8%B8%D8%A9_%D8%AF%D9%87%D9%88%D9%83). لا يظهر أي رابط إنترنت في واجهة الطالب، وتظل اللعبة كاملة العمل دون إنترنت.

## الاختبار

تم التحقق محلياً من فتح إعداد اللعبة، عرض SVG والمحطات، ظهور سؤال، صعود المتسلق بعد إجابة صحيحة، وبقاء المتسلق مكانه بعد إجابة خاطئة مع تمرير الدور، ومن عدم وجود أخطاء JavaScript في المتصفح.
