# تصميم محطة X/O

تعمل لعبة X/O داخل مسار الرحلة فقط. اللوح 3×3 في مركز الشاشة، وتحيط به بطاقتا الفريقين. الخلايا كبيرة للمس وتكبر للشاشات 4K؛ لون X ذهبي دافئ ولون O سماوي.

لمس مربع فارغ يفتح نافذة سؤال كبيرة في الوسط. لا تغلق النافذة بالـ Escape أو لمس الخلفية قبل الإجابة، كي تبقى العلاقة واضحة: سؤال واحد مقابل مربع واحد. بعد الإجابة تظهر تغذية راجعة قصيرة وزر واحد لتثبيت العلامة أو تمرير الدور.

الرسوم أصلية في CSS: مدار X/O، توهج الدور، ولوح زجاجي. لا توجد مكتبة، CDN، أو صورة خارجية. يحترم التصميم `prefers-reduced-motion`.
