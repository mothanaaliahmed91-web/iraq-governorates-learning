# نظام واجهة رحلة دهوك — الشاشة الصفية

## المساران

- البداية: بطاقتان مستقلتان «انطلق في الرحلة» و«استكشف دهوك».
- الرحلة: بوابة → خريطة SVG → اكتشاف باللمس → تصنيف → مطابقة → ترتيب → اختبار → جواز.
- المعلومات: خمس بطاقات موضوعية، أقضية ونواحٍ، معرض. لا نقاط أو اختبار أو شارات أو انتقال للألعاب. زر العودة الوحيد خارج هذا المسار هو «العودة للمسارين».
- `mode` يحمي معالجات الألعاب والنقاط؛ لا يكفي إخفاء عناصرها بصرياً.

## مساحة الشاشة

مرجع التصميم 3840 × 2160 بنسبة 16:9. الخط الأساسي يتدرّج من 16px عند 1920 إلى 32px عند 3840. الشبكة تستخدم كامل العرض؛ لا حد عرض يحصر الواجهة وسط 4K. في العرض الصفّي، الترويسة ومسار الرحلة والتحكم خارج مساحة المحتوى القابلة للتمرير. التخطيط الأصغر يعيد توزيع البطاقات، ويبقي شريط التحكم مثبتاً أسفل الشاشة.

- لمس الأزرار: `max(64px, 3.9rem)`، بما في ذلك أزرار الإغلاق والمراحل.
- خط محلي: Tahoma / Segoe UI. لا تحميل خطوط من الشبكة.
- الصور: `object-fit: contain`؛ تُحفظ الخرائط والصور كاملة.
- اتجاه RTL أصيل؛ لا تعطيل لتكبير الصفحة.

الزجاج بطبقات شفافة وحدود خفيفة، دون مرشحات ضباب كثيفة. رسوم الجبال ومسار الماء SVG أصلية تعليمية رمزية وليست خرائط حدود. الخريطة القديمة تبقى SVG قابلة للنقر مع توضيح أنها مبسطة، وتجاورها خريطة المالك المرجعية. صورة النيون موجودة في بوابة الدرس والمعرض وليست بديلاً للخريطة التفاعلية.

## التفاعل والوصول

- Pointer Events للسحب مع pointer capture وpointercancel؛ بديل مكافئ: المس البطاقة ثم التصنيف، أو استخدم لوحة المفاتيح.
- نافذة تفاصيل `<dialog>` مع حصر التركيز، Escape، زر إغلاق كبير، لمس الخلفية، وإعادة التركيز إلى البطاقة.
- نجاح مرئي مع صوت لطيف؛ الخطأ يعطي تلميحاً. لا عد تنازلي ولا انتقال مؤقت يفاجئ الطالب.
- كل نشاط يدعم إعادة المحاولة والتخطي؛ «التقدم» متاح دائماً. كل سؤال له زر للسؤال التالي.
- النقاط مرة واحدة لكل إنجاز؛ إعادة المحاولة وزيارة المرحلة لا تضاعف النقاط.
- إعادة البداية تصفّر الرحلة. المعلومات لا تغيّر حالة النقاط.
- حركات ظهور قصيرة 180ms، نبض عند اللمس فقط. `prefers-reduced-motion` يوقف كل الانتقالات والحركات.

## الصوت والعمل دون إنترنت

المؤثرات فقط: نقر ونجاح وتلميح خطأ عبر Web Audio مع AudioContext واحد قابل لإعادة الاستخدام. لا موسيقى، لا تعليق صوتي، لا speechSynthesis، ولا استيراد لملف narration القديم. كتم المؤثرات فوري. تعذّر الصوت لا يمنع التفاعل. لا فيديو تلقائي ولا مكتبات أو CDN أو اتصالات خارجية.

## إعادة تصميم الشاشة الرئيسية

- شاشة صفية 16:9 بتخطيط شبكي: عنوان الدرس وبطاقتا المسارين يساراً، وخريطة SVG تفاعلية كبيرة يميناً، وثلاث بطاقات محاور عريضة في الأسفل. يعاد ترتيبها عمودياً عند العرض الضيق.
- الخريطة تبقى SVG قابلة للمس والنقر؛ دهوك خضراء زمردية، والأنهار خطوط سماوية توضيحية لا تدّعي حدوداً أو بيانات خرائطية إضافية. أضيفت خريطة العراق المرفقة كمرجع مصغر لا كبديل للتفاعل.
- أضيفت طبقات جبال CSS، وهالة ودبوس نابضان، وشبكة خلفية هندسية؛ الحركة قصيرة وتتوقف مع `prefers-reduced-motion`.
- رأس زجاجي داكن بلمسات نيليّة وبنفسجية، شعار المدرسة كعلامة خلفية خافتة، وشريط تحكم دائري كبير أسفل الشاشة.
- صور `maps/reference/1.jpg` و`2.jpg` و`3.jpg` مستخدمة في بطاقات محاور ومعرض الصور. لعدم وجود أسماء أماكن موثقة ضمن الملفات، لا تنسب التسميات صوراً بعينها إلى دهوك أو إلى معلم محدد.
- يتاح بديل بصري تلقائي عند فقد أي صورة، وتبقى النصوص التعليمية مستقلة عن الصور.
